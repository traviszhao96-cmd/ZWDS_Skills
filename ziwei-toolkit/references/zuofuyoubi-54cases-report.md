# 左辅右弼 54例 完整分类分析报告

## 规则总纲（来源：260531新视频 + 260515番外篇 + 初阶P07）

### 左辅 = 壬天干主宰，老阳，男星，物质/实际
- 实在的，在什么宫位该宫位事情必定存在且不一般
- 心性：务实、执念、无明(预设立场)、耿耿于怀
- 标准用法：左辅位置 + 壬天干位置 -> 两宫同参
- 【子宫锁】左辅在子宫 = 锁定，不轻易改变
- 【壬同宫=离心自化】能量离开盘面
- 【生年科】某物质存在会"给出去"

### 右弼 = 戊天干主宰，老阴，女星，灵魂/灵性
- 灵魂(归藏易坤卦)、高我、先天感觉、潜意识
- 心性：好静、受业力牵引
- 标准用法：右弼位置 + 戊天干位置 -> 两宫同参
- 【五干加强】丙/戊/己/辛/壬在右弼宫 = 加强先天感觉
- 【生年科】精神/天赋有但保不住
- 【戊同宫】能量自循环，自我驱动

### 孤阴 = 太阴+右弼同宫
- 两个女星同宫 -> 极阴 -> 灵性极高/第六感超强 + 体质偏弱

### 左右同宫 = 拧巴
- 左辅要物质，右弼要精神 -> 既要又要 -> 患得患失
- 左辅动+右弼静 -> 同宫时动大于静
