# 命盘分析

## 用途

这份方法用于把一张紫微斗数原盘,稳定地讲成一套有顺序、能落地、能复盘的命格分析。它适合两类场景:

- 实际论命:用户给出生资料或命盘,要求分析命格、六亲、格局、大限。
- 教学训练:用户要学习一套固定的原盘论命步骤。

核心原则只有四条:

1. 先定盘,后论命。
2. 先看体,后看用。
3. 先看原盘格局,再看时间引动。
4. 先回答"是什么",再回答"为什么",最后回答"何时应"。

## 固定输出顺序

最终回答尽量收束成这六段:

1. `定盘`
2. `命格主轴`
3. `六亲`
4. `体用落地`
5. `核心宫位与触发点`
6. `大限总论`

如果是教学型回答,可以把这六段展开成"七步法";如果是实际论命,就按这六段给结果。

## 第0步:定盘 · 命宫分析

### 目标

先把盘定稳,再通过命宫把人的底色看透。命宫分析是整盘的锚点--看懂命宫,人的先天性格和后天走向就有一条主线。

### 要做的事

1. 确认历法、性别、时间、是否需要校时。
2. 确认命宫、身宫、来因宫、生年禄权科忌。
3. 按顺序做完：命宫三层 → 四化人格 → 星有本宫 → 命宫=来因宫，最后收束三句话。
4. 把六条本对线先定出来:命迁线、兄友线、夫官线、子田线、财福线、父疾线。



### 步骤0-A:命宫分析

命宫不是只看主星,要从四层同时切入。任何一层漏看,结论都可能是偏的。

#### 第一层:命宫主星--人格风格

- 命宫无主星 → 借对宫迁移宫主星来论,此人对外表现即为真实性格
- 命宫单主星 → 以此星为核心,再看辅星修饰
- 命宫双主星 → 两星并重,互动模式是重点(如紫微+破军=权威欲+破坏欲共存)
- 命宫主星的庙旺利陷 → 相同主星,落陷与庙旺判若两人(见后附:星有本宫表)

#### 第二层:命宫生年四化--先天动力

检查命宫是否被生年四化点到:

| 命宫有 | 含义 |
|--------|------|
| 生年禄 | 天生带资源、人缘好、出手大方、随和 |
| 生年权 | 天生强势、有主见、执行力强、控制欲 |
| 生年科 | 天生体面、有贵人、爱面子、重名声 |
| 生年忌 | 天生执着、认真、对自己严苛、有拧巴感 |
| 无双象 | 命格单纯,不复杂 |
| 有双象/三象 | 多重动力并存,内在外在不一致 |

**特别关注**:命宫有生年忌时,此人一生有"我执"--做什么都带着一种"非得如此不可"的劲儿。

#### 第三层:命宫自化--后天变化

命宫自化不可当孤象看,必须回头连生年四化:

| 类型 | 现象 | 需回头查 |
|------|------|---------|
| 命宫离心自化禄 | 资源主动分给他人 | 把哪宫的禄甩出去了? |
| 命宫离心自化权 | 把掌控力放出去 | 谁接了这个权? |
| 命宫离心自化科 | 体面放给他人 | 谁沾了你的光? |
| 命宫离心自化忌 | ⚠️ 自我消耗、对自己失望感重 | 命宫本气向对宫/他宫发散 |
| 命宫向心自化 | 外来能量拉回命宫 | 是谁在往命宫送能量? |

#### 命宫分析收束

三个问题串一遍:
1. 此人表面给人什么感觉?(主星+庙旺)
2. 此人天生带着什么动力?(生年四化)
3. 此人后天会怎么变化?(自化)

### 四化人格特质

四化不仅是功能性的(禄=资源、权=权力),更是人格类型的底层分类。看懂了一个人的主导四化,就看清了他的行为模式和思维习惯。

#### 科型人格(科为最强)

- **核心特质**:计划型、重名声、爱面子、讲体面
- **思维模式**:做事先想流程、讲逻辑、求周全
- **优势**:有条理、有贵人、能获得名义/头衔
- **弱点**:想太多、行动慢、容易被空想耽误
- **职业倾向**:教育、顾问、幕僚、品牌管理
- **木主仁**:心软、容易为人着想

#### 权型人格(权为最强)

- **核心特质**:掌控型、要权力、执行力强、敢冲
- **思维模式**:做事求快求果、看准就干
- **优势**:行动力强、能扛事、能带团队
- **弱点**:脾气大、得罪人、不顾他人感受
- **职业倾向**:管理、创业、军警、竞技
- **火主礼**:明快直接,不管弯弯绕

#### 禄型人格(禄为最强)

- **核心特质**:随和型、资源多、好说话、乐于分享
- **思维模式**:做事讲究舒不舒服、顺不顺手
- **优势**:人缘好、资源便利、生活滋润
- **弱点**:容易懒、不够拼、得过且过
- **职业倾向**:销售、接待、慈善、享受型行业
- **金主义**:讲义气、大方

#### 忌型人格(忌为最强)

- **核心特质**:执着型、认真、较真、不放手
- **思维模式**:做事钻到底、精益求精、不饶过自己
- **优势**:靠谱、执着、能把事做透
- **弱点**:拧巴、焦虑、给自己和身边人压力
- **职业倾向**:技术、研究、审计、质量管理
- **水主智**:思虑深、但也容易钻牛角尖

#### 人格判断顺序

1. **先看命宫有无生年四化** → 有则以此四化为主导人格
2. **看生年四化中哪个落在命宫** → 优先级最高
3. **看哪个四化落在来因宫** → 来因宫的四化是先天动力
4. **如果没有四化直接落在命宫** → 看命宫主星偏哪个四化气质

#### 过犹不及(补充)

四化人格的分型不是越多越好。任何四化过量都会从优势滑向问题:

| 过量类型 | 正常面 | 过量表现 |
|---------|--------|---------|
| 禄太多 | 资源多、人缘好 | 懒散、贪图享受、不思进取 |
| 权太多 | 执行力强、能掌控 | 霸道、失控、四处树敌 |
| 科太多 | 有条理、体面 | 空想、犹豫不决、纸上谈兵 |
| 忌太多 | 认真、执着 | 焦虑过度、自我攻击 |

**判断标准**:同一宫位汇聚双象以上即偏重;全盘同一四化出现次数最多者最可能过度。

### 星有本宫(庙旺利陷)

主星不只看名字,更要看它落在哪里。同一颗星,庙旺与否差别巨大。

| 星曜 | 庙旺(本宫) | 落陷(最弱位) | 庙旺表现 | 落陷表现 |
|------|------------|--------------|---------|---------|
| 紫微 | 午 | 子 | 帝王气、自带格局 | 孤寡、自以为是 |
| 天府 | 戌 | 卯 | 稳重、善于管理 | 保守过度、不愿冒险 |
| 太阳 | 卯(庙) | 酉 | 热情外放、正能量 | 阴沉、父缘薄 |
| 太阴 | 酉(庙) | 卯 | 细腻周到、情商高 | 情绪化、多变 |
| 武曲 | 辰戌 | 巳亥 | 果断有钱、理财强 | 刚愎、钱来快去也快 |
| 天同 | 巳亥 | 卯 | 福气厚、心宽 | 懒散、没心没肺 |
| 廉贞 | 寅申 | 巳亥 | 精明、社交手腕强 | 偏激、自毁倾向 |
| 贪狼 | 辰戌 | 巳亥 | 多才多艺、交际王 | 欲望失控、放纵 |
| 巨门 | 辰戌丑未 | 巳亥 | 口才好、善分析 | 口舌是非、阴暗 |
| 天相 | 丑未 | 卯酉 | 辅佐力强、公正 | 没主见、随大流 |
| 天梁 | 丑未 | 巳亥 | 正直、长者风范 | 管闲事、自以为是 |
| 七杀 | 寅申 | 巳亥 | 杀伐果断、开拓者 | 冲动、不计后果 |
| 破军 | 子午 | 寅申 | 破而后立、革新 | 破坏、情绪失控 |
| 天机 | 巳亥 | 丑未 | 灵敏、善谋划 | 机关算尽、反复 |

**记忆口诀**:
- 帝星紫微最喜午,天府戌位最安稳
- 日月分喜卯与酉,阳喜晨光阴喜月
- 杀破狼各有所居,廉贞七杀守寅申

**应用**:命宫主星先判庙旺落陷,再配上四化,结论才准确。落陷的忌比庙旺的忌严重得多;落陷的禄也可能只是小甜头。

### 命宫=来因宫(特殊解)

来因宫恰好是命宫,意味着"人就是为做自己而来"。这是最常见但也最容易被误判的格局。

**关键特征**:
1. 来因=命宫时,命宫的四化权重最高,远超其他宫位
2. 此人一生的核心是"自我实现",不是为别人活
3. "我执"重--不论忌在不在命宫,都有一种"非我莫属"的感觉
4. 命宫飞忌如果落在他宫,说明此人为了"做自己"会主动背责

**解盘顺序改变**:来因=命宫时,常规解盘顺序(先看来因再看四化落点)改为:
1. 命宫生年四化
2. 命宫自化
3. 命宫飞宫
4. 再看来因在其他宫位的含义
5. 然后再看全盘其他四化

因为来因就在命宫,命宫一句话已经把"为什么而来"讲完了。

### 收束:三句话

1. 这个人的核心性格驱动是什么。
2. 这个人的最大优势在哪里。
3. 这个人的命理核心课题是什么。

### 这一步要说明什么

- 这张盘是否是"当前工作盘"。
- 命宫的四层分析是否已做完，人格标签是否已打。
- 有没有时辰未验证的风险。

## 第1步:身宫分析

### 目标

身宫是后天运势的归宿。命宫看"你是谁",身宫看"你最终在哪里落脚"。30岁后身宫影响日益显化,是定盘的最后一道安检。

### 要做的事

1. 确认身宫所在宫位及地支。
2. 做身宫三层检查:生年四化 → 离心忌 → 两忌叠加。
3. 对身宫做风险定级。
4. 如有来因宫,做身宫×来因联动。

---

### 身宫的本质

| 维度 | 命宫 | 身宫 |
|------|------|------|
| 层次 | 先天 | 后天 |
| 领域 | 性格、天性、与生俱来 | 运势、肉身、立身处世 |
| 时间 | 终身底色 | 30岁后日益显化 |
| 代表 | "你是谁" | "你最终在哪里落脚" |

### 身宫三层检查

**检查一:身宫所在宫位的生年四化?**

- 身宫在生年禄位 → 后天落脚于资源与舒适
- 身宫在生年权位 → 后天落脚于掌控与成就
- 身宫在生年科位 → 后天落脚于体面与名声
- 身宫在生年忌位 → ⚠️ 后天落脚于执念与压力,该宫事务一生难逃

**检查二:身宫是否有离心自化忌?**

- 有 → ⚠️ 身宫自带离心忌,落脚之处天然向外发散损耗,难以凝聚

**检查三:两忌叠加?**

- 身宫同时有生年忌 + 离心忌 → 🔴 高危。双忌夹身宫,命局最脆弱点

### 身宫风险定级

| 身宫状态 | 等级 | 含义 |
|---------|------|------|
| 身宫无四化 | ✅ 正常 | 后天走向跟随命宫基调 |
| 身宫有禄/权/科 | ✅ 正面 | 后天落脚于优势领域 |
| 身宫落在生年忌 | ⚠️ 注意 | 后天归宿恰好是先天课题 |
| 身宫有离心忌 | ⚠️ 注意 | 落脚之处自带损耗 |
| 两忌叠加 | 🔴 高危 | 一生很难脱离此宫事务 |

### 身宫与来因宫联动

| 来因宫 | 身宫 | 解读 |
|--------|------|------|
| 命宫 | 忌位 | 为自己而来,最终落脚于困难课题--天生劳碌命 |
| 命宫 | 禄位 | 为自己而来,最终有资源安身--天生好命 |
| 夫妻 | 忌位 | 为感情而来,最终感情成纠缠 |
| 迁移 | 禄位 | 为外缘而来,最终外在顺遂 |
| 财帛 | 忌位 | 为钱而来,最终被钱困住 |

## 第2步：命格主轴 · 格局分析

### 目标

在命宫与身宫分析完成后，对全盘十二宫做统一评分，形成"天赋地图"。这一步把零散的宫位吉凶系统化，看清三件事：

1. **先天→后天的人生主线**：命宫 vs 身宫 分数对比，看人生是从低走高还是从高走低
2. **天赋宫位在哪**：高分宫 = 耕耘易有收穫的领域，坐实了就是优势
3. **薄弱宫位在哪**：低分宫 = 需要规避或借高分宫补强的领域

### 评分体系

**公式**：`总分 = 起评 5 + 本宫_raw + 对宫 + (三方_raw ÷ 2)`

- 本宫_raw：主星+吉煞星+四化+自化的原始总和，不封顶
- 对宫：忌冲 -2 / 煞星 -1 / 中平 0 / 吉星有力 +1
- 三方_raw：两个三合宫各按本宫规则独立评分后求和
- 三方÷2：防止三方过度主导总分
- 总分不封顶，自然拉开差距

#### 本宫格局细则

**主星**：
- 庙 +2 / 旺 +1.5 / 得 +1 / 平 0 / 不 -1 / 陷 -2
- 双主星取平均值

**吉星**（每颗 +0.5）：左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马、三台、八座、龙池、凤阁、天贵、天官、天福、封诰、红鸾、天喜、天德、月德、恩光、天厨、天寿、华盖、台辅

**煞星**（每颗 -1，庙旺减半）：擎羊、陀罗、火星、铃星、地空、地劫

**杂凶**（每颗 -0.3）：天空、旬空、截路、空亡、天哭、天虚、天伤、蜚廉、寡宿、阴煞、天刑、破碎

**中性**（0）：天姚、天才、咸池、解神、天巫、天使、年解

**四化**：
- 生年禄/权/科：+1 /个
- 生年忌：-2 /个
- 自化禄/科：+0.5 /个
- 自化权：+0.5 /个
- 自化忌：-2 /个

#### 对宫冲照

| 对宫状态 | 分值 |
|---------|------|
| 对宫有忌冲（生年忌或自化忌正冲） | -2 |
| 对宫有煞星 | -1 |
| 对宫中平 | 0 |
| 对宫吉星有力 | +1 |

#### 三方辅佐

两个三合宫各按本宫规则独立评分后求和，再除以 2（防止三方过度主导）。

计算：三合宫 = (本宫 index ± 4) mod 12

### 命宫 vs 身宫：先天→后天主线

| 对比 | 解读 |
|------|------|
| 命宫 > 身宫 | 早年有优势，后天需更努力维持 |
| 命宫 ≈ 身宫 | 先天后天一致，人生走势稳定 |
| 命宫 < 身宫 | 早年受压，越往后越顺 |

### 能量浓度评分（第二维度）

格局评分回答“这个宫好不好”，能量浓度回答“这个宫忙不忙”。两个维度独立并存，交叉才能看到完整画面。

**公式**：`能量浓度 = 星曦亮度总和 + 主星数 × 1.5 + 四化总数 × 2`

- 星曦亮度：庙 3 / 旺 2.5 / 得 2 / 平 1.5 / 不 1 / 陷 0.5（每颗主星独立计算后求和）
- 主星数：宫内主星数量（含借对宫）
- 四化总数：生年四化 + 自化（禄权科忌各算1次，不论正负）

> **注意**：能量浓度不分好坏——忌也加分，禄也加分。它只衡量“能量堆积程度”，不判断吉凶。

#### 四象限矩阵

| 象限 | 质量分 | 浓度分 | 含义 | 策略 |
|------|--------|--------|------|------|
| **福报型** | 高 | 高 | 能量用在了好地方，耕耘即有收获 | 重点发力，天赋主场 |
| **病灶型** | 低 | 高 | 能量过载且有伤害，越忙越容易出事 | 警示宫位，减少主动介入 |
| **隐藏型** | 高 | 低 | 底子好但没被激活，需要外部引动 | 等待大限流年激活，或飞宫四化来激活 |
| **空白型** | 低 | 低 | 两个维度都弱，需要飞宫四化来激活 | 不主动投入，靠借力 |

#### 应用规则

1. 每个宫位同时算两个维度：格局评分（质量）+ 能量浓度（浓度），交叉定位象限。
2. **病灶型宫位是全盘风险点**：高浓度 + 低质量 = 能量用在了坏事上。如赵迁移宫（廉贞庙+双忌）。
3. **福报型宫位是全盘发力点**：高浓度 + 高质量 = 最佳投入产出比。如阿汤财布（武曲庙+贪狼庙+自禄权）。
4. **隐藏型宫位是等待开发的宝藏**：格局好但浓度低，等大限流年激活。
5. **空白型宫位不等于废宫**：可能是空宫借对宫、或需飞宫四化确认实际能量。

#### 速查案例

| 命例 | 宫位 | 质量 | 浓度 | 象限 |
|------|------|------|------|------|
| 赵 | 迁移 | 低 | 高(双忌) | 病灶型 |
| 姥爷 | 迁移 | 高 | 高 | 福报型 |
| 苏轼 | 兄弟 | 中 | 极高(14.5) | 病灶型 |
| 阿汤 | 财布 | 高 | 高(13.0) | 福报型 |
| kiky | 仆役 | 高 | 高(13.0) | 福报型 |

#### 为什么两个维度不能合并

- **格局评分**：衡量星曦本身的格局好坏（庙旺=好，落陷=差），回答“值不值得投入”
- **能量浓度**：衡量四化/星曦的集中程度（禄权堆积=高，忌叠加=也高），回答“会不会被这个问题缠上”

合并会丢失关键信息：jeremy兄弟宫能量14.5（双忌压顶）看起来“很强”，但质量极低（双忌是负向）；阿汤财布13.0（禄权堆积）看起来“能量爆炸”，质量也高——两者的“13分”含义完全相反。

### 天赋地图：十二宫排名

从高分到低分排列十二宫（使用格局评分/第一维度）：

- **高分宫**：天赋领域，在此宫相关事务上努力易有收稾
- **中等宫**：正常水平，稳扎稳打
- **低分宫**：薄弱领域，需规避或借助高分宫支援

## 第3步：有六亲信息时，先定位，再解关系

### 目标

六亲分析不是先讲关系,而是先找到人。

### 要做的事

1. 如果用户给了六亲生肖,先定位六亲用神宫位。
2. 定位顺序固定:
   - 先看生年四化本宫与对宫是否直接命中。
   - 不中,再走有体路用。
   - 再不中,再走禄随忌走或科随权走。
   - 仍不中,再考虑时辰有误。
3. 定位完成后,再讲关系。

### 关系分析只讲三层

1. 宫位空间:这段关系主要落在家庭、事业、外缘、精神、合作,还是资源分配。
2. 星曜特质:对方像什么样的人,彼此用什么方式互动。
3. 四化动力:为什么会亲近、牵制、亏欠、依赖或拉扯。

### 如果没有六亲信息

直接省略这一步,不要为了完整而硬讲。

## 第4步：由体入用，把命格翻成现实问题

### 目标

把"这个人天生是什么样"翻成"这个人会在哪些现实问题上发用"。

### 核心定义

- `体`:生年四化。是先天格局、本质、现象。
- `用`:自化与飞宫。是后天运用、动作、发用方式。

### 要做的事

1. 从生年四化所在宫位起飞,同类追踪:
   - 禄转禄
   - 权转权
   - 科转科
   - 忌转忌
2. 优先看 `忌转忌`,因为它最容易把问题讲具体。
3. 把飞到的宫位,当成对前面"体"的补充说明:原来的问题到底落在家庭、钱、工作、身体还是感情,原来的优势到底拿去帮谁、换什么、伤哪里。
4. 再做第二层承接:
   - 禄随忌走
   - 科随权走
5. 需要时加入 `有用归体`:
   - 事件已经从"用"飞出后,再回头看这颗化星的生年源头宫位。
   - 用来交代事件的来源、关联方、资源出处。

### 河图洛书与合十的使用位置

- `河图 / 合十`:偏静态,拿来看先天格局,哪条线是根本盘。
- `洛书`:偏动态,拿来看问题会怎么动、怎么串、怎么往后发展。

## 第5步：由用归体，结合自化、平方、平衡找核心宫位

### 目标

从一堆问题里,找出真正的主战场。

### 自化怎么用

1. 自化不是单独吉凶,它是变化和引动。
2. 自化一定要回头连到生年四化,不能脱体空讲。
3. 区分两种能量:
   - 离心:向外发散、发用、做出来、放出去
   - 向心:向内牵引、拉回来、凝聚到本宫

### 平方怎么用

平方是高强度结构,不是普通细节。优先级很高。

判断时抓三点:

1. 平方落在哪一宫或哪条线。
2. 它让本宫与对宫哪里"不稳定"。
3. 它后面又引动了谁,特别是生年忌和后续忌转忌。

### 平衡怎么用

当一个宫位的能量不对等时,不要停在原宫,要继续看为了补平衡又飞出什么。

这类飞出的能量常常是"以后释前":后面飞到哪里,就说明前面那个问题会在哪个场景做实。

### 如何找真正的核心宫位

通常真正的核心宫位,会同时满足几项中的多项:

1. 被来因宫点到。
2. 有生年忌、平方或强自化。
3. 又被飞忌、同位宫、对宫反复串联。
4. 六亲用神也落在这里或冲到这里。
5. 这宫位一动,多个专题一起被牵动。

## 第6步：意外分析——命迁子田

### 目标

应用前四步的结果，排查命盘中的意外/官非/刑伤风险。命迁子田四条宫位构成两道安全防线——是由用归体后的第一次专题风险扫描。

### 要做的事

1. 锁定命迁线（命宫+迁移宫）和子田线（子女宫+田宅宫）四个宫位。
2. 逐个检查四宫有无生年忌或离心忌：命/迁有忌→出门风险；子/田有忌→家宅享乐风险。
3. 判断忌冲方向：忌不冲对宫多为内伤；冲对宫才是外显的灾。
4. 两条线有无交叠忌冲：交叠即 🔴 高危。
5. 叠加煞星检查（羊陀/火铃/白虎/天刑/破碎）。
6. 输出风险等级：✅ 安全 / ⚠️ 单项风险 / 🔴 交叠高危。

---

### 命迁子田：为什么是这四个宫？

| 宫位 | 代表面 | 与意外的关系 |
|------|--------|------------|
| 命宫 | 我自己、身体 | 人身安危的第一线 |
| 迁移宫 | 外出、外在环境 | 出行安全、外部遭遇 |
| 子女宫 | 晚辈、享乐、桃花 | 娱乐场所、因享乐惹事 |
| 田宅宫 | 家宅、房产、家庭 | 居家安全、家宅变故 |

命迁线看"我出门"——在外是否安全；子田线看"家宅与享乐"——家里和休闲场所是否平安。两条线一旦有忌互冲，就是意外信号。

### 基本判断规则

**第一步：四个宫各自有没有忌？**

- 命宫/迁移宫有生年忌或离心忌 → 出门先天带风险（命宫忌=自己引来的，迁移忌=外面找来的）
- 子女宫/田宅宫有生年忌或离心忌 → 家宅/享乐场所有隐忧
- 宫位无忌 → 该线基本安全

**第二步：忌有没有冲对宫？（这是关键）**

忌不冲对宫则多为内伤（自己难受），忌冲对宫才是外显的灾：

| 忌所在 | 冲对宫 | 含义 |
|--------|--------|------|
| 命宫忌 | 冲迁移 | 自己惹事、身上带灾出门 |
| 迁移忌 | 冲命宫 | 无妄之灾、外界找上门 |
| 子女忌 | 冲田宅 | 因享乐/桃花/下属伤及家宅 |
| 田宅忌 | 冲子女 | 家宅变故牵连外出/子女 |

**第三步：两条线有没有交叠？**

- 命迁线的忌同时冲入子田线方向 → 🔴 出门的灾连着家里
- 子田线的忌同时冲入命迁线方向 → 🔴 家宅问题变成人身安危
- 两条线各自有忌但方向不交叉 → ⚠️ 两个独立风险区，严重性减半

### 煞星叠加

命迁子田四宫中任何一个，如果忌与煞星同宫：

| 叠加配置 | 风险类型 |
|---------|---------|
| 忌 + 擎羊/陀罗 | 血光、刀伤、手术 |
| 忌 + 火星/铃星 | 突发灾祸、火灾、爆炸 |
| 忌 + 白虎 | 丧事、白事牵连 |
| 忌 + 天刑 | 官非、诉讼、牢狱 |
| 忌 + 破碎 | 物品损毁、财产损失 |

### 特殊组合

- 命宫忌 + 迁移宫自化忌 → 自己出门就出事（主动找灾）
- 田宅忌 + 子女宫桃花星（贪狼/廉贞/天姚）→ 因桃色事件牵连家宅
- 迁移宫忌 + 迁移宫有擎羊 → 交通意外倾向（需结合大限流年确认应期）
- 四宫全无四化 → 该方面平顺，无需特别标注

## 第7步：把原盘问题放进时间轴，先看大限，再谈应期

### 目标

原盘负责定格局,大限负责看哪十年最容易把问题做实。

### 基本顺序

1. 本命定格局。
2. 大限看趋势。
3. 流年找引动。
4. 流月做确认。

### 原盘分析里,大限重点看什么

1. 哪一步大限走到来因宫。
2. 哪一步大限走到生年忌宫。
3. 哪一步大限走到平方宫或其对宫。
4. 哪一步大限走到专题正宫。
5. 哪一步大限走到六亲用神宫位。

### 叠宫法的使用

真正要断应期时,重点不是把所有流年宫都讲一遍,而是看:

- 流年命宫叠在本命哪一宫。
- 同时又叠在大限哪一宫。

这两个宫位交叉出来的主题,就是那一年最容易发生的大事。

### 解释顺序不能乱

走到某宫以后,固定按这顺序讲:

1. 生年四化
2. 自化
3. 飞宫

## 第8步：最后收束成可交付的命格结论

### 目标

避免讲成很多碎象,最后却没有一句话结论。

### 固定收束法

一张原盘讲完,尽量收成五个结论:

1. 一句话命格总论。
2. 三个核心优势。
3. 三个核心风险。
4. 六亲关系主线。
5. 哪几个十年最关键。

## 轴线速查

### 六条本对线

- 命迁线:自我、外界、移动、环境
- 兄友线:亲近同辈、大众人际、合作关系
- 夫官线:婚姻关系、社会角色、事业舞台
- 子田线:家庭、成家、房产、子女、桃花、投资
- 财福线:赚钱、享受、欲望、福报、精神满足
- 父疾线:原生家庭、长辈、学习、证照、身体

### 高频专题线

- 命迁子田:常用于看意外、外出、变动、家内家外的连锁问题
- 夫官线:常用于看婚姻与社会角色如何互相牵动
- 父疾线:常用于看原生家庭、身体、学习与责任感的根底

## 常见误区

1. 还没定盘,就开始下结论。
2. 六亲未定位,就先讲关系好坏。
3. 只讲命宫星曜,不讲来因宫与生年四化。
4. 只讲四化落宫,不讲对宫与轴线。
5. 看到自化就直接断吉凶,不回头找生年四化。
6. 看到流年就直接下结论,不先讲原盘和大限。
7. 说了一堆象意,却没有收成一句话命格总论。
